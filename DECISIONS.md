# Решения

Короткие записи «что решил — почему». Одна строка на решение.

- **Движок: Godot 4.7** — 2D из коробки, бесплатный, лёгкий для новичка.
- **Язык: GDScript** — встроен в движок, не требует отдельной установки.
- **Версии: git + GitHub** — история и резервная копия проекта в одном месте.
- **Рендер: Mobile, D3D12** — настройки по умолчанию Godot для Windows.
- **Реальное время, не пошагово** — бои должны идти динамично, без остановок на раздумья.
- **Непрямое управление** — игрок строит и управляет базой, юниты действуют сами. Убирает выделение и приказы, оставляет фокус на стратегии.
- **PvE против ИИ, без сети на старте** — сеть добавляет синхронизацию и рассинхроны; вернёмся, когда будет играбельное ядро.
- **Карта фиксированная, уровень = отдельная сцена** — проще балансить и рисовать вручную; генерация позже.
- **Ландшафт через TileMapLayer** — стандартный способ Godot, удобно рисовать карту и хранить типы клеток.
- **Территория без визуальных границ** — контроль читается по ландшафту и постройкам; возможен лёгкий индикатор.
