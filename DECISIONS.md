# Решения

Короткие записи «что решил — почему». Одна строка на решение.

- **Движок: Godot 4.7** — 2D из коробки, бесплатный, лёгкий для новичка.
- **Язык: GDScript** — встроен в движок, не требует отдельной установки.
- **Версии: git + GitHub** — история и резервная копия проекта в одном месте.
- **Рендер: Mobile, D3D12** — настройки по умолчанию Godot для Windows.
